# 三维位置输入接口

更新日期：2026-09-28。本次功能仅影响三维显示，不发送运动命令，不参与工作台结果计算。以太网或串口接收模块尚未实现。

## 运动关系

光栅尺尺身固定于床身，光栅读数头与螺母、防转座、滑台及滑块共用位移输入。丝杠旋转由独立转角输入驱动，联轴器暂按1:1直联显示。没有转角输入时保留当前旋转姿态，不从位移、导程或转速猜测转角。

加载连接杆仍为几何联动，不是电缸独立实测位置。若提供电缸反馈，需另行确认安装坐标、零点、方向及与连接杆的约束，不能把它与光栅尺位置混用。

## 立即试用

进入“三维联动”，点击“导入位置 JSON”，先选择 `examples/position-only.json`，再选择 `examples/position-and-angle.json`。两份文件均为示例而非实测数据。第一份将滑台移到25mm；第二份移到55mm并给出π/2弧度转角。显示零点或方向曾修改时，先在三维设置中恢复默认。

导入后显示“导入快照 · 非实时”，不会伪装成实时传感器接收。工作台模拟测试不会覆盖导入的位置，点击“恢复模拟显示”才重新跟随模拟器。导入不会停止工作台中正在运行的模拟测试，也不把快照写进测试结果。

## 数据结构 v1

```json
{
  "version": 1,
  "session": "DEVICE-RUN-001",
  "sequence": 1,
  "time": 0.05,
  "position": 25.0,
  "valid": true
}
```

必填：version为1；session为采集会话编号；sequence为非负递增整数；time为设备相对时间，单位秒；position为螺母滑台采集位移，单位mm；valid为采样质量标志。

可选：angle（丝杠转角，rad）、rpm（转速，rpm）、force（轴向力，N）、torque（输入转矩，N·m）。缺失或null显示为“--”，不补零。未知字段、缺失必填字段、非有限数值或不支持的版本被拒绝。

位移不要求是硬件绝对式编码，可使用有明确参考零点的累计位移。原始脉冲、微米和角度制数据须由适配器先换算成mm与rad。重复或乱序数据不更新位置，同一会话内时间不得倒退；重新开始采集时更换session。

显示位移 = (position - 显示零点) × 显示方向。当前示意模型的名义行程0-100mm，边界容差1mm，超界保持最后姿态并显示提示；这不是实际设备安全限位。

## 后续实时接入

采集适配器取得位置后，构建 `ScrewBench.MotionSnapshot`，调用 `MechanismView.UpdateMeasured(snapshot, deviceState)`。方法支持从后台线程调用并转交WPF界面线程，模型状态来自传入的设备状态。此方法仅是程序内接口，不是已开放的TCP端口。

实时输入显示“外部实测输入”；数据来源由调用端保证，不应将示例数据标记为实测。运行中1秒无新有效帧显示超时并保持姿态。文件导入则是单帧快照，不自动轮询文件。当前没有独立的电缸位置或任意部件六自由度输入。

实际接线前请提供：一帧真实数据、传输方式、字段单位、采样周期、位置零点、正向定义和实际行程。收到后再实现协议解析、时间同步与实机验证。
