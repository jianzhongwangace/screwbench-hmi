# 卧式丝杠测试平台三维联动

日期：2026-09-07。

## 模型依据

以项目根目录 `8a879bd6c32f53f655d94af2fac49862.jpg` 为外观及机构布局参考，由用户确认采用二维图重建。最终使用程序化三维几何，不加载立式丝杆推力机STEP。此前转换的STEP资源仅为探索产物，未列入当前应用发布资源。

左侧为驱动电机、两组联轴器及扭矩传感器，中间为支撑、被测丝杠、螺母与防转滑台，右侧为加载连接件及电缸。前侧为光栅尺、读数头、限位与机械挡块。所有外形尺寸、螺纹细节和连接结构均为显示示意，不是制造图或运动学验证模型。

## 数据与运动对应

| 部件 | 数据/约束 | 当前实现 |
| --- | --- | --- |
| 被测丝杠 | 实际转角 Angle，rad | 绕X轴旋转，轴向固定；不按速度积分产生角度 |
| 螺母及防转座 | 实际位移 Position，mm | 沿X轴平移，不跟随丝杠旋转 |
| 滑台、滑块、光栅读数头 | 与螺母刚性连接 | 共用同一位移，不假定各有一个传感器 |
| 电机轴、联轴器 | 与丝杠1:1直联假设 | 同角度旋转，电机及转矩传感器外壳固定 |
| 力传感器及安装座 | 随滑台移动 | 力值用于显示，不以力反推位置 |
| 加载杆、浮动关节 | 两连接端的几何关系 | 按滑台位置改变可见杆长及关节位置，无独立电缸反馈 |
| 床身、导轨、支撑、尺身、设备外壳 | 固定结构 | 不动 |

显示位移 = (采集位移 - 显示零点) × 方向；转角采用同样的零点与方向变换。显示模型1单位对应1mm，不放大微小游隙。示意行程名义范围0至100mm，边界留1mm显示容差，越界时报警提示并保持最后模型姿态，不静默截断数据。该范围不是设备真实软限位。

显示坐标设置只影响三维，不修改传感器标定、计算结果或控制器。设置保存在本机WebView2显示配置中。接入实机后须核对位移基准、方向、有效行程、实际传动比及各轴独立通道。

## 运行边界

当前WPF桥接仅传递SIMULATED数据，未新增硬件通信。前端具备接收规范化位置帧的能力，不代表真实采集已经完成。接入实机时应从独立采集线程取得同步位置与转角，并明确传入真实数据来源，不得通过改标签把模拟数据称为实测。

暂停、停止、故障时保持最后采样姿态；运行中超过1秒没有新的有效序号时显示数据超时。无效采样和乱序帧不更新模型。三维不外推未来位置，不独立播放循环动画；观察视角可以继续旋转。三维不是安全监控器，不能替代硬件急停、限位、STO和底层保护。

当前不包含热场、应力场、磨损推演、故障预测或剩余寿命预测，仅为数据驱动的机构可视化。

## 文件与验证

- `src/Desktop/Scene/mechanism.js`：参考图三维结构及部件运动关系。
- `src/Desktop/Scene/mapping.mjs`：位置映射、有效性与超时状态。
- `src/Desktop/Scene/scene.js`：Three.js视图、选中部件、视角与数据接收。
- `src/Desktop/MechanismView.cs`：WPF内嵌离线WebView2及单向数据桥接。
- `tools/scene/mapping.test.mjs`：位置、转角、零点、乱序、无效帧自检。
- `tools/scene/qa.mjs`：Playwright运动映射、操作、像素及多尺寸截图检查。
- `qa/scene`：浏览器自检截图及结果。

WPF的 `--smoke` 自检另检查内嵌WebView2的位置是否与同一采样值一致，并覆盖原有四模式测试流程。标定零点应恢复默认后进行该自检。
