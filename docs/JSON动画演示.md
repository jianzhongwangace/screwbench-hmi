# JSON动画演示

日期：2026-09-28。此功能使用编造数据，完全不连接真实设备，也不生成实测结果。

进入三维页点击“播放演示 JSON”，或使用项目中的“播放演示.cmd”。螺母、滑台、滑块及光栅读数头在10-80mm之间往复运动，8秒一个循环；丝杠和联轴器按示例2mm导程对应的角度正反转，加载杆为几何联动。可暂停、继续、停止。

演示源文件为 examples/motion-demo.json。frames给出时间、位移及角度关键帧，播放采用余弦缓入缓出插值；转速由插值角度变化率计算；loadN=100、leadMm=2、efficiency=0.9均为编造的演示参数，用来合成正反向力和转矩，绝不作为测试或验收数据。缺少其他通道的普通位置快照仍显示--，不会自动补造。

五个数据框显示转矩、转速、轴向力、位置、转角，均随演示变化。框放在模型上方和下方；长折线的末端圆点跟随对应部件，视角变化时重新投影，移出视野的锚点隐藏引线。角度锚点表示被测丝杠的测量对象，不代表本版本新增了实体编码器模型。

正式输入真实数据时应停止演示并使用测量适配器；导入位置快照、恢复模拟显示或接收UpdateMeasured均会停止演示。演示不改变工作台中的测试数据或计算逻辑。
